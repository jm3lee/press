palette with tailored typography and component treatments:

- `midnightPulse`: High-contrast neon accents for dark, cinematic creatives.
- `oceanBreeze`: Teal-forward palette ideal for wellness or travel stories.
- `forestCanopy`: Verdant tones designed for sustainability messaging.
- `monochromeFocus`: Editorial monochrome with decisive contrast ratios.
